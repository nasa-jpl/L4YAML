    Scripts.Ledger — the Rule 9 ledger and its gate logic #

    Rule 9 (Blueprint/06-discipline.md): every script this repository runs is a Lean program; no new scripts/*.py. scripts/scripts-ledger.txt is the record of the Python that still exists, one row per script:

    # open: 85
scripts/flip_census.py | I | todo
scripts/repin.py | I | lean:scripts-repin
inline:.github/workflows/test-coverage.yml:python3 - | G | todo

    A row key is a .py path under scripts/ or inline:<file>:<command prefix> for a python3 -c … / python3 - <<EOF site in a shell wrapper or workflow. Class is the plan's (Blueprint/09-scripts-in-lean.md §1): G gate, I instrument, F flip/price, R report. Status is todo, lean:<exe> (ported; the Python is deleted and <exe> is a lean_exe in lakefile.lean) or exception:<reason> (plan §4).

    The # open: N header pins the number of open rows (todo + exception). The gate requires the count to equal the pin, so the pin is a reading and not a ceiling: a conversion lowers it in the same PR, a new Python script cannot land without raising it, and the raise is visible in the diff — the ledger may only shrink.

    This module is the pure half: parsers for the two line shapes (a ledger row, a shell/YAML line that invokes python) and the check over the inventory an IO driver collects (Scripts/Main/CheckScriptsLedger.lean). Every parser has #guard rows below taken from the tree.

                                                    Python invocations in shell and workflow text #

                                                    The scan is shell-shaped, not line-shaped: \-continued physical lines are one logical command line; a quoted string is one word that carries its quotes ("import weasyprint"), with inner blanks collapsed; a word beginning inside an open quote is never a command; an interpreter counts only in command position — first word of a simple command, after |, ||, &&, ;, (, {, $(, !, after if/then/else/elif/ do/while/until/exec/command/time/nohup/env, after a VAR=val prefix, or after a YAML key (run:) at the head of the line. A top-level word starting with # ends the line (a comment). The interpreter is python, python3, a path ending in one, or $NAME / "$NAME" / ${NAME} for a NAME=…python3 assignment found anywhere in the same file.

                                                    What one interpreter word in command position is followed by. cmd is the command prefix: the interpreter word and its arguments up to the first shell operator (|, &&, ;, a redirect, a heredoc), blanks collapsed — the text an inline row is keyed by.
