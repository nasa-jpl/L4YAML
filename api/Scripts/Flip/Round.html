    Scripts.Flip.Round — one build round of a flip, and the sorry step #

    A round builds a target, reads the log, and bills every error site in the flipped file to its enclosing declaration (Scripts.Lean.BuildLog, the same resolver as scripts-flip-census). One round is a FLOOR: Lean stops at the first failing module. sorryBodies replaces the body of each broken declaration with sorry so a next round can see past it; a spec asks for rounds > 1 to iterate to the fixpoint (no new sites). The pushed tree never carries a sorry: the driver restores the file byte-identically afterwards.
