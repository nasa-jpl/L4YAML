    Scripts.Flip.Patch — anchored replacement, the pure half of a flip #

    A flip spec names a file at a revision and a list of (anchor, replacement) pairs. Each anchor must occur exactly count times (one, unless the spec says otherwise) in the text it is applied to, or the run refuses before touching the tree — the protocol every scripts/flip_*.py wrote by hand (if t.count(old) != 1: sys.exit(...)). Patches apply in order, each to the output of the previous one, as the Python's sequential str.replace did.
