    Scripts.Lean.BuildLog — file:line:col: error: lines and the declaration that owns them #

    The port of scripts/flip_census.py (plan Blueprint/09-scripts-in-lean.md §3 phase 2.1). A flip is priced by the DISTINCT DECLARATIONS it breaks, not by error sites: one lemma can log four errors and is still one proof to repair. This module reads a lake build log, resolves each error site against the source on disk by scanning backwards for the nearest declaration opener at column 0, and separates gate sites (#guard, #eval, #guard_msgs, #check, #print, #reduce) from proofs — a gate is a decision to re-take, not a proof to repair, and billing it to the preceding def is wrong (measured 2026-10-18: three #guards in Serialization/Census.lean all reported as def tagCases).

    A single run reports a FLOOR, never the price. A failing module blocks its dependents, so the next layer never elaborates. To get the whole bill, sorry the round's breakages, rebuild, re-run; repeat until a round adds nothing but sorryAx artifacts.

    The parsers are hand-written for the fixed line shapes (plan §6 Q1: no regex dependency) and mirror the Python's ERR, COMMAND and OPENER regexes one for one; the #guard rows below are the Python's cases.
