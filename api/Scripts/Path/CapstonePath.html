    Scripts.Path.CapstonePath — the ∨ True audit's positions, ON or OFF the capstone's path #

    DOCS item 439 ((ω-path)). A P ∨ True cannot make the capstone unsound, only weak; the risk the owner refuses to carry is the set of positions whose vacuous arm weakens a fact the capstone actually consumes. This module is the pure classifier: it takes

    • the ∨ True audit's pinned tables (Tests/Guards/Proofs/OrTrueAudit.lean: expectedPositions, expectedSupply, expectedConsumers), and
    • the set of constants the capstone reaches — the transitive closure, through types and values, of what DocumentProduction.scan_strict_proof / parse_strict_proof use (reach), the only two capstones that import StreamAccum,

    and classes every position:

    classmeaning
    on-spenttop binder of a reached lemma whose own proof cases on the disjunction (cased>0)
    on-relayedtop binder of a reached lemma passed on whole (passed>0, never cased)
    on-fieldconstructor field of a reached inductive — read by the reached lemmas that case on the park
    on-conclusionthe [ret] of a reached lemma — the fact it hands its callers is the weakened one
    on-nesteda ∨ inside a binder's statement of a reached declaration
    on-othera reached top position outside the supply/consumer tables (another module)
    off-unreadtop binder of a reached lemma whose proof never reads the binder (cased=0 passed=0, value readable)
    off-unreachedthe declaration is not in the capstone's closure

    on-* is the owner's ON set; off-* is residue by class. The guard Tests/Guards/Proofs/CapstonePathAudit.lean pins the reading off the elaborated environment; lake run capstone-path (Scripts/Main/CapstonePath.lean) recomputes it off the built .oleans and the audit file's text and prints it.
