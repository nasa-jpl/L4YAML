    FromYaml and ToYaml Type Classes #

    Type classes for converting between YAML and Lean types, inspired by Lean's FromJson/ToJson pattern.

    Architecture #

    Three typeclasses form the conversion pipeline:

    • FromYamlType — conversion from resolved YamlType (post-schema-resolution)
    • FromYaml — conversion from raw YamlValue (pre-resolution)
    • ToYaml — conversion from Lean type to YamlValue

    The default FromYaml instance bridges to FromYamlType via Schema.resolve, so most users only need to implement FromYamlType.

    Instances Provided #

    • Primitives: Unit, Bool, Int, Nat, String, Float
    • Collections: Array α, List α, Option α
    • Maps: Std.HashMap String α

          def L4YAML.Schema.coreScalar (tag content : String) :
          YamlValue

          A plain scalar carrying a Core Schema tag. The tag records that the value is a null / bool / int / float rather than a string that happens to spell one, so the dumper can emit it bare (true, not "true") and a reader applying the Core Schema recovers the type.

            @[instance_reducible]
            instance L4YAML.Schema.instToYamlString :
            ToYaml String

            A string is plain unless the Core Schema would read its content as something else (true, null, 42, 1.5, ""): then it is double-quoted, which under §10.3.2 pins it as a string. So a String and a Bool never collide: toYaml "true" is "true", toYaml true is !!bool true.

            def L4YAML.Schema.floatContent (f : Float) :
            String

            YAML spelling of a float: toString writes NaN/inf/-inf, which the Core Schema does not recognize; §10.3.2 wants .nan/.inf/-.inf.

            Equations
            • L4YAML.Schema.floatContent f = if f.isNaN = true then ".nan" else if f.isInf = true then if f < 0 then "-.inf" else ".inf" else toString f
