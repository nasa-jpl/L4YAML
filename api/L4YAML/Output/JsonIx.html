    L4YAML.Json.streamToJsonIx

    Core-Schema JSON Emitter — indexed-pipeline twin #

    streamToJsonIx is streamToJson with the parse swapped from legacy TokenParser.parseYaml to the indexed TokenParser.Indexed.parseYamlIx. It exists so the yaml-test-suite matrix can score the indexed pipeline against the same in.json oracles the legacy pipeline scores 100% on (DOCS.md § Indexed-pipeline parity gap, plan item 5). All JSON serialization (docsToJson, schema resolution, escaping) is shared, so any score difference is attributable to scan/parse alone.
