    Align — a column-aligning YAML formatter #

    L4YAML.Align.format rewrites a YAML text so that, inside each block mapping, the values of key: value entries start in the same column, and so do the nodes of key: &anchor value / key: !tag value entries (a second column for the node after the properties). It is a whitespace-only transformation:

    • The scanner (scanWithComments) locates every block-mapping entry whose key, : indicator and value start lie on one line.
    • Only the whitespace run between : and what follows it, and the run between the last node property and the node, are rewritten. Comments, blank lines, block-scalar bodies, flow collections, quoting and continuation lines are copied byte for byte.
    • The result is re-scanned and must yield the same tokens and the same comments (positions aside); otherwise format refuses and returns the error instead of a changed text (fail-closed).

    Group shape and the "reasonable" cap are configured by AlignConfig:

    • grouping := .mapping aligns a whole block mapping (blank and comment lines do not split it); .run splits a mapping at blank lines.
    • maxCell caps the key cell (key start to value start, inclusive of the colon and the gap). A key wider than the cap keeps minGap spaces and does not drag the rest of its group to the right.
    • round pads every cell up to a multiple of round columns.

    What is proved (L4YAML.Proofs.Output.AlignProofs): the edit application preserves every non-blank character in order (hence the line structure), format succeeds only with token- and comment-identical output, and the cell arithmetic never produces a gap narrower than minGap.
