    Scalar Collection Coupling #

    Coupling theorems for scalar content collection functions, connecting the scanner's scalar-scanning loops to the formal surface syntax.

    Each scalar scanning function preserves ScannerSurfCorr on every .ok return path. Content-string accumulation and token emission are irrelevant to correspondence since they only affect tokens/simpleKey/comments fields, none of which appear in ScannerSurfCorr.

    §7 Where a plain-scalar fold lands (DOCS item 71) #

    [134] s-ns-plain-next-line(n,c) requires at least one ns-plain-char after the fold. The scanner enforces that with its content-length check, but the production proof can only use the check once it knows the fold does not land on a break or on s-white: an all-white line between two breaks is an l-empty line, consumed by the fold itself, and both fold helpers end with skipWhitespace. These four lemmas say exactly that.

    source
    theorem L4YAML.Proofs.ScalarCoupling.foldQuotedNewlinesLoop_stop (s : Scanner.ScannerState) (cnt fuel : Nat) (hfuel : s.inputEnd - s.offset ≤ fuel) :
    Scanner.blankLineTabUnderFloor (Scanner.foldQuotedNewlinesLoop s cnt fuel).fst = true ∨ ∀ (ch : Char), (Scanner.skipWhitespace (Scanner.foldQuotedNewlinesLoop s cnt fuel).fst).peek? = some ch → CharPredicates.isLineBreakBool ch = false

    foldQuotedNewlinesLoop stops either at a tab under the floor — which its caller turns into tabInIndentation — or at a line whose first non-s-white character is not a break: every all-white line in between is an l-empty.
