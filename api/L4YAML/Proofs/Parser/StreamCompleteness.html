    Stream completeness — TokenGrammar ∧ TokenStateOk → parseStream = .ok #

    The parser half of the grammar-completeness converse: a token array of the right shape (TG) under the right per-document state (TokenStateOk) is accepted by parseStream. The proof is one induction on the TG derivation, carrying Inv (parser state ⊇ the event environment at the current position) and a span-proportional fuel bound.

    Proof-internal per-token trace (scaffolding, not a model) #

    TokenStateOk is stated over TokenEvents.tokenEvents, which keeps a document's %TAG handles pending until its ---. The environment bookkeeping below needs a trace that is compositional token by token, so it uses a PRIVATE per-token twin (perTokenEvents/perTokenTrace): a document begins at its first directive (or at a --- not preceded by directives), a %TAG declares its handle on the spot. The two traces are EQUAL on every TokenGrammar stream (perTokenTrace_eq_tokenEvents, via spec [209]'s --- after a non-empty directive run), which is the one bridge perTokenOk_of_tokenStateOk from the public premise to this scaffolding; nothing outside this file sees it (EVENTSOF-CONCEPT §9, S5 slice 2; 7.7 parse_iff_grammar).
