    WellFormedAnchorsS preservation through parseNode #

    Proves that parseNode preserves WellFormedAnchorsS: if the input anchors satisfy it, so do the output anchors.

    The predicate is ParserWfaScannable's — every value in the anchor table is Scannable after stripping — and not the Grammable-valued WellFormedAnchors. Grammable has no alias constructor, so that reading is false of the table the parser builds for a node that has itself as a descendant via an alias: a collection's anchor binds only after its items are resolved, so its own interior alias never sees it. See Tests/Guards/Proofs/AliasNodeRoute.lean for both halves of that, and plan row 20 for why the chain is the one that had to move.

    Architecture: strong induction on fuel, the same pattern as the AG proofs. Sub-parsers only modify anchors through recursive parseNode calls, so the predicate propagates through each by the induction hypothesis. The only non-trivial case is applyNodeFinalization, and it is now ParserWfaScannable's applyNodeFinalization_wfaS — which, unlike its Grammable original, asks for no AllAliasesResolve premise. That is what takes this chain off the AAR clique entirely; the AAR chain's own capstones (3.5-3.7) are a separate question.
