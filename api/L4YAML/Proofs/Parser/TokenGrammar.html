    Token grammar — the token image of the surface grammar #

    TG ts s i j is an inductive relation over index spans of a token array: "tokens [i, j) derive the nonterminal s". It is NOT defined by running the parser; it mirrors the productions parseStream/parseNode/… follow (L4YAML/Parser/TokenParser.lean) so that parseStream_accepts (StreamCompleteness.lean) can be proved by induction on the derivation.

    TokenStateOk ts is the stateful half: the per-document anchor/tag-handle discipline, stated as SerializationWellFormed of the event trace the tokens denote (TokenEvents.tokenEvents, the serialization layer's own extractor), so §3.2.2.2 is read off the existing Event/Env vocabulary rather than re-invented.
