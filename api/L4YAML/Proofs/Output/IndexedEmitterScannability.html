    The migration is organized across seven sub-files under Proofs/Output/IndexedEmitterScannability/ rather than mirroring the legacy file's monolithic shape. The split is by architectural concern, not by line count:

    Sub-fileLegacy linesLOC est.Concern

    ScanChain.lean842–1300~460ScanChain inductive + helpers
