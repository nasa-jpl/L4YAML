    FlowStackChainIx — flowStack moves in lockstep with flowLevel (indexed) #

    Indexed mirror of Proofs/Output/EmitterScannability/FlowStackChain.lean. ScannerStateIx.flowStack is written only by the four flow-collection functions (scanFlowSequenceStartIx/scanFlowMappingStartIx push a kind marker and increment flowLevel; scanFlowSequenceEndIx/ scanFlowMappingEndIx pop it and decrement flowLevel). Every other scanner function copies the field through record updates. This file makes that lockstep precise across a full scanNextTokenIx step and lifts it to balanced scan chains:

    • §1 — flowStack preservation suite for every scanner leaf reached by scanNextTokenIx outside the four flow open/close functions. Mechanical clones of the _preserves_simpleKeyStack suite in Production/IndexedScannerPlainScalarValid.lean §12: the originals are field-agnostic structural walks, so the same scripts prove the flowStack twins verbatim.
    • §2 — flow open/close flowStack component facts + preprocess / per-dispatcher preservation.
    • §3 — scanNextTokenIx_dispatchFlowIndicators_flowStack_step: the 5-arm fact for the flow-indicator dispatcher (preserve / push true / push false / pop) — includes the 9a kind-check throw arms.
    • §4 — scanNextTokenIx_flowStack_step: the per-step trichotomy — one scanner step either preserves flowStack (and flowLevel), pushes one kind marker (incrementing flowLevel), or pops one (decrementing it).
    • §5 — FlowMonoChainIx.flowStack_invariant / FlowMonoChainIx.flowStack_eq: a balanced scan chain never disturbs the flowStack entries below the floor; a chain that starts and ends at the floor preserves flowStack exactly.

    theorem L4YAML.Proofs.Indexed.EmitterScannability.FlowMonoChain.scanNextTokenIx_dispatchFlowIndicators_flowStack_step {input : String} (s s' : Scanner.Indexed.ScannerStateIx input) (c : Char) (h : s.scanNextTokenIx_dispatchFlowIndicators c = Except.ok (some s')) :
    s'.flowLevel = s.flowLevel ∧ s'.flowStack = s.flowStack ∨ s'.flowLevel = s.flowLevel + 1 ∧ s'.flowStack = s.flowStack.push true ∨ s'.flowLevel = s.flowLevel + 1 ∧ s'.flowStack = s.flowStack.push false ∨ s.flowLevel > 0 ∧ s'.flowLevel + 1 = s.flowLevel ∧ s'.flowStack = s.flowStack.pop

    The 5-arm flowLevel/flowStack fact for the indexed flow-indicator dispatcher: [ pushes true, { pushes false, ]/} pop (with flowLevel > 0 from the level guard and the 9a kind check dead in the ok arms), and , preserves both fields.

    §4 Per-step trichotomy #

    source
    theorem L4YAML.Proofs.Indexed.EmitterScannability.FlowMonoChain.scanNextTokenIx_flowStack_step {input : String} {s s' : Scanner.Indexed.ScannerStateIx input} (h : s.scanNextTokenIx = Except.ok (some s')) :
    s'.flowLevel = s.flowLevel ∧ s'.flowStack = s.flowStack ∨ s'.flowLevel = s.flowLevel + 1 ∧ s'.flowStack = s.flowStack.push true ∨ s'.flowLevel = s.flowLevel + 1 ∧ s'.flowStack = s.flowStack.push false ∨ s.flowLevel > 0 ∧ s'.flowLevel + 1 = s.flowLevel ∧ s'.flowStack = s.flowStack.pop

    One scanNextTokenIx step moves flowStack in lockstep with flowLevel: it either preserves both, pushes one kind marker (true for [, false for {) while incrementing flowLevel, or pops one while decrementing flowLevel (which was positive).

    §5 Chain theorems over FlowMonoChainIx #

    source
    theorem L4YAML.Proofs.Indexed.EmitterScannability.FlowMonoChain.FlowMonoChainIx.flowStack_invariant {input : String} {fl₀ : Nat} {t s' : Scanner.Indexed.ScannerStateIx input} {n : Nat} (h : FlowMonoChainIx fl₀ t n s') (base extra : Array Bool) :
    t.flowStack = base ++ extra → extra.size = t.flowLevel - fl₀ → t.flowLevel ≥ fl₀ → ∃ (extra' : Array Bool), s'.flowStack = base ++ extra' ∧ extra'.size = s'.flowLevel - fl₀

    Through a FlowMonoChainIx with floor fl₀, the flowStack entries below the floor are never disturbed: if the start state's stack splits as base ++ extra with extra tracking the excess flow depth (extra.size = flowLevel - fl₀), the end state's stack is base ++ extra' with extra' tracking the end state's excess depth. Pops always stay inside extra because the chain keeps flowLevel ≥ fl₀.

    A balanced FlowMonoChainIx — starting and ending at the floor flow level — preserves flowStack exactly.
