    AlignProofs — what the column aligner guarantees #

    • applyEditsFrom_filter / applyEdits_filter: edit application preserves every non-blank character, in order — so the text outside the rewritten blank runs is untouched, and (applyEdits_count_newline) the line structure is preserved.
    • format_ok_filter: a successful format is such a whitespace-only edit.
    • format_ok_scanShape: a successful format yields the same token values and the same comments as its input — the fail-closed check is sound.
    • minGap_le_gap: a cell that takes part in alignment is never squeezed below minGap blanks.
