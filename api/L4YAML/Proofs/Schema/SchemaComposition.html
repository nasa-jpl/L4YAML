    Schema Composition Proofs (Phase 7.5) #

    Proves round-trip properties for the composed schema layer:

    1. resolve ∘ toYaml — schema resolution correctly recovers type information
    2. fromYaml? ∘ toYaml — the full type conversion round-trips

    Key Results #

    §1: resolve ∘ toYaml Primitive Correctness #

    For each primitive ToYaml instance, resolve (toYaml a) produces the expected YamlType constructor. All primitive ToYaml instances produce plain scalars with no tag, so resolution goes through resolveImplicit.

    §2: resolve ∘ toYaml Collection Structure #

    Collections preserve their shape through resolve ∘ toYaml.

    §3: fromYamlType? Inversion Lemmas #

    Each FromYamlType instance correctly inverts its YamlType constructor.

    §4: fromYaml? ∘ toYaml Round-Trip #

    For types with both ToYaml and FromYaml (via FromYamlType), fromYaml? (toYaml a) = .ok a.

    §5: String Schema-Safety #

    Strings require a precondition: the content must not be implicitly typed as null/bool/int/float by Core Schema §10.3.2 precedence.

    §6: Int/Nat Round-Trip #

    Generic round-trip for Int and Nat with isInt (toString n) precondition, plus concrete instances via native_decide.

    §7: #guard Compile-Time Composition Checks #

    Zero Axioms #

    All theorems are machine-checked. No sorry, no axiom, no partial.

    §5: String Schema-Safety #

    Under Core Schema §10.3.2, plain scalars are implicitly typed: null → bool → int → float → string. The toYaml String instance emits a plain scalar only when implicit resolution of the content is already a string, and a double-quoted scalar otherwise — and a quoted scalar is a string under §10.3.2 whatever it spells. So every string resolves to itself, with no schema-safety precondition.

    §6: Int/Nat Round-Trip #

    Int and Nat require isInt (toString n) = some n as a precondition since the isInt parser is not kernel-reducible. Concrete instances are proved by discharging the precondition via native_decide. (The !!int tag the instances carry means null/bool are never consulted.)
