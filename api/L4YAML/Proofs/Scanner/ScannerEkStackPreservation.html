    explicitKeyStack preservation suite (scanner leaves) #

    ScannerState.explicitKeyStack (item 98) is written only by the four flow-collection functions (scanFlowSequenceStart/scanFlowMappingStart push the outer explicit-key stamp, scanFlowSequenceEnd/scanFlowMappingEnd pop it while restoring the pair). Every other scanner function copies the field through record updates. This file discharges that "every other function" half: a _preserves_explicitKeyStack lemma for each scanner leaf reachable from scanNextToken outside those four, up to the three non-flow per-character dispatchers.

    The proofs are mechanical clones of the _preserves_flowStack suite in ScannerFlowStackPreservation.lean with the field renamed: the originals are field-agnostic structural walks (unfold + split + fuel induction bottoming out in emit/advance preservation), so the same scripts transfer verbatim. The chain-level lift (FlowMonoChain.ekStack_eq) lives beside flowStack's in Proofs/Output/EmitterScannability/FlowStackChain.lean.

    §1 explicitKeyStack preservation suite (scanner leaves) #

    Clones of the _preserves_simpleKeyStack suite in Proofs/Scanner/ScannerCorrectness.lean with simpleKeyStack renamed to explicitKeyStack: the original proofs are field-agnostic structural walks (unfold + split + fuel induction bottoming out in emit/advance preservation), so they transfer verbatim.
