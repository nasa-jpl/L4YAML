    closeStaleExplicitKey — the projection lemmas (item 333) #

    The last step of scanNextToken_preprocess (the indexed twin is in CloseStaleExplicitKeyIx) ends a pending explicit key whose entry a sibling has closed. It writes explicitKeyLine/explicitKeyCol and NOTHING else, so every other projection of the state passes through unchanged; the preprocess lemmas peel it off the outside with these rewrites before reasoning about the key save.

    The hook is the identity or exactly the re-read of the register off the pending-key stack with the closed level's key cleared (item 335: an outer ? survives, a lone ? dies).
