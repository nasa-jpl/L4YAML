    The register witness, stated and seeded (DOCS item 342) #

    Item 340 built the flip (PackAlt sc := ExplicitValueRefused sc) to a fixpoint and found 72 consumer sites STARVED: a park whose register is LIVE owes the informative side of its pack — the ? the register names and that ?'s route to the stream — and nothing in the scanner state said which ? that was. Item 338's Sound ties the register to the innermost marked slot of pendingKeys; this module ties each marked slot to a surface ?:

    • AtCol input c sp — sp is a suffix of input standing at column c. Item 341 named this relation AtLineCol; the LINE half is not stated. No fact in the tree relates sc.line to the input (ScannerSurfCorr carries col_eq and input_prefix, nothing about newlines), so a line component would have no cursor bridge and the seed could not pay it. No consumer reads the register's line (item 338 deleted the hook's line != ekLine guard), so the column and the suffix are the whole of what the witness must say.
    • QuestionEntry input sp_start c sp_q — the informative side of the ?-entry pack, keyed by the ?'s column: sp_q stands at c, reads ?, and every [186] entry it opens closes the stream.
    • SlotWitness input sc sp_start i — a marked slot pendingKeys[i] = some l at column indentColumns[i] = c has a QuestionEntry at c in input — the stream's constant, taken as a parameter rather than read off sc.input so no writer owes an input-preservation lemma (item 343).
    • RegWitness sc sp_start — outside flow, a live register (some l, c) has a QuestionEntry at c; regWitness_of_slots derives it from RegOk and the slot witnesses (innermost_some_mem), so the writers carry the slots.
    • scanKey_witness — the seed: the ? just scanned is sp_q, its route is the premise question_open_map already holds (h_expl's informative side).

    The writer lemmas through scanNextToken are item 343's; the flip that reads inl/inr off the register is item 344's.

                    §3 The writers (DOCS item 343) #

Everything else is SlotsWitness.transport.
