    closeStaleExplicitKeyIx — the projection lemmas (item 333) #

    The last step of scanNextTokenIx_preprocess and scanNextTokenIx_preprocessWC ends a pending explicit key whose entry a sibling has closed. It writes explicitKeyLine/explicitKeyCol and NOTHING else, so every other projection of the state passes through unchanged; the preprocess lemmas peel it off the outside with these rewrites before reasoning about the key save.
