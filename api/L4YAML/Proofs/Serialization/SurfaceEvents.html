    Surface-derivation semantic event witnesses #

    This module attaches serialization events to actual L4YAML surface derivations, rather than scanning indicator-looking characters globally.

    The key design point is structural: aliases and properties are witnessed only where the grammar says they are nodes/properties. Quoted scalar text, comments, and block scalar contents therefore cannot become semantic events merely by containing '*', '&', or '!'.

    Anchor commitment is represented separately from lexical property discovery: an anchor property yields a pending anchor name; current L4YAML commits it at node completion, while YAML 1.2.2 commits it before content. Both policies are explicit in CommitTrace.
