    Runtime document-scope bridges #

    The independent semantics resets anchor and custom-tag state at document boundaries. This file pins the corresponding executable scope facts:

    • scanner document-start resets its anchor-name environment;
    • parser document preparation replaces (rather than extends) its tag-handle table with the declarations of the current document.

    These are family-level facts; no fixed-input evaluation is used.

      Directive order and document reset #

      beginDocument is a semantic scope-start, not the lexical --- position. An eventual whole-input extraction must place it before that document's preceding %TAG directives. This definition pins the order, not the extraction.
