    Scanner-output shape: S3's premises for parseStream_ok_checkFrom #

    parseStream_ok_checkFrom (S5, ParseCheckFrom.lean) takes scanner facts about scanFiltered input = .ok ts as premises. This module discharges them for real scanner output.

    • (a) TagUsesShaped ts — scanFiltered_TagUsesShaped, from TagShape.scanFiltered_emitOk (the per-token TagInv carried over scanLoop: the only arm that builds a .tag is scanTag, whose handles are "", "!!", "!" or "!" ++ word-chars ++ "!"), bridged to the parser's BuiltinTagHandle ∨ isNamedHandle by tagOk_shaped.
    • (b) DirectivesClosed ts — scanFiltered_DirectivesClosed, from DirectiveRuns.scanFiltered_closedList (the directiveWithoutDocument / directiveAfterContent refusals, carried through the scan loop as DirInv).
    • (c) streamEnd-last — scanFiltered_streamEnd_last: the output is non-empty and its last token is .streamEnd (scanLoop emits it last, and the placeholder filter keeps it). This alone does not make S5's consumed prefix the whole array: parseStreamLoop stops before consuming .streamEnd, so S5's witness k may be ts.size - 1. The separate argument is scanFiltered_streamEnd_index (.streamEnd is the only such token, so that k is ts.size - 1) plus tokenEvents_dropLast_streamEnd (.streamEnd adds no event); together, scanFiltered_parseStream_ok_checkFrom_full carries S5's verdict to all of ts.
    • The scanner-shape facts that discharged parseStreamLoop's no-progress exit (LoopDead / DeadResidue, items 446–452: liveF_dead_contra, scanFiltered_noComment, scanFiltered_bal_tok) are deleted (item 506): since (γ2α) that exit is an error, scanFiltered_parseStream_ok_checkFrom_full concludes checkFrom {} (tokenEvents ts) = true outright, and no slice of S3 reached them.
