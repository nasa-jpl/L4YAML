    Exact executable acceptance boundary #

    This module records the selected factorization for the load-capstone work. InExecutableLanguage is the scanner-plus-token-parser acceptance language. Since composition is total, it accepts exactly the same inputs as parseYaml.

    This theorem isolates the remaining, separate language bridge: relating the current-L4YAML executable boundary to exact surface syntax and the independent serialization event semantics. The current-runtime anchor completion policy is distinct from YAML 1.2.2 anchor-start commitment (see CommitTrace). This factorization is not an exactness theorem for the normative YAML language.
