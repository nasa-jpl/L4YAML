    S3 slice (4), PR 1 — the content step's T twin #

    (EVENTSOF §10, capstone 7.7 parse_iff_grammar; item 486)

    accum_step_content (StreamAccum) concludes its arm, ContentArm (item 484). This module reads the arm into the TraceOf twins, the way accum_step_flow_trace reads FlowArm:

    • goOut_push — the trace of one pushed token, in goOut form (the tokenEvents equation item 485 wrote is only true once no %TAG handle is pending; the twins couple through goOut, as 2c states it);
    • SFlowNode_head_lift — the first-char lift: an SFlowNode whose first character is none of & * ! [ { is its content, SNsPlain / SCDoubleQuoted / SCSingleQuoted;
    • accum_step_content_trace_in — depth ≥ 1: the value arms land on the T flow stack through TFlowOpenStack.receiveNode, the property arms leave it (the tail is kept), the block scalars are refused;
    • accum_step_content_trace_out — depth 0: every arm's T leaf.

    The depth-≥1 receive's premises (h_tail, h_lead) are the ones accum_step_content_core derives from h_interior for its own FlowOpenStack.receiveNode; the twin takes them as stated and the derivation stays the core's (no StreamAccum edit; item 486 prices the replay). (b) — the parser's refusal of a held run followed by an alias at depth 0 — does not enter here: the twin concludes the alias LEAF; (b) is spent where the depth-0 node is assembled.
