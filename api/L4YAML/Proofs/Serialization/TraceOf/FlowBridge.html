      Key contexts #

      [110] nb-double-text(n, block-key | flow-key) is [111] nb-double-one-line, so a quoted scalar is a derivation in a KEY context only when the scanner's run stayed on its line (s'.line = sc.line); the body then transports between the two key contexts (SNbDoubleText's two key arms are the same relation). Where the encoded grammar reads a key at .flowKey is inFlowCtx .blockKey — a flow collection as a BLOCK implicit key — and there the scanner enforces the one-line rule itself (invalidImplicitKey), so the premise is available. Keys INSIDE flow collections are read at the collection's own context (TFlowMapEntry.implicitValue / TFlowSeqEntry.pairValue take TFlowNode n c, c = .flowIn), whose quoted body is multi-line: the flow re-walk discharges them through the content twins above (lifted to .flowIn by ScalarFoldAt.SCDoubleQuoted_multiCtx), NOT through these — the scanner accepts {"a⏎ b": c} and so does the encoded grammar (P102 (x) pins the set; item 464).
