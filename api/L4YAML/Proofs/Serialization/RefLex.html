    refLex — the executable twin of Skeleton (Step 5a(iii), slice 2) #

    A reference lexer over List Char, written in the shape of the grammar and independent of Scanner/IndexedScanner: it finds where the event lexemes (&, *, !, %TAG, ---, ...) are, treating quoted scalars, comments, block-scalar bodies and plain scalars as opaque. eventsOf input := (refLex input).map eventsOfSegs. Soundness against Skeleton and the corpus census against parseYaml live beside it (EVENTSOF-CONCEPT.md §7).
