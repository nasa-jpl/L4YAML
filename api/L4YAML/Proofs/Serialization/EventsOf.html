    eventsOf — the lexical skeleton (Step 5a(iii), slice 1) #

    EVENTSOF-CONCEPT.md §3. An input's serialization trace is a function of a skeleton: a canonical partition of the source into segments, each event segment derivable by its surface relation at its column, each opaque segment a quoted scalar / comment / block-scalar body / plain scalar, and the remaining text in maximal other runs that contain no event lexeme. No scanner or parser definition is imported here.
