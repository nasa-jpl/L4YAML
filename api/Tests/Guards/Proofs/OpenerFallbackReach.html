    Opener fallback reachability (item 375, PR #139 review follow-up) #

    Tests/AdversarialInstantiation.lean's Priority 43 reads the scanner's landings and the parser's verdict on the openers' sibling inputs — the UNREFUTABLE leg of item 375's reading. It cannot read which arm of an opener's five-way route match (h_routeE) a proof takes: that is a term-level fact (§7 — a pin on a Prop is vacuous), so it is read here off the proof terms, with RelaySupplyCensus's edge walker.

    For each of the five opener lemmas the fallback arm is the catch-all of the match on the optional contexts (_ ∨ True binders: h_res_land, h_sfx_land, h_nodoc_land, h_mk_land, h_pr_land, …). The fallback is REACHABLE from a caller exactly when that caller supplies EVERY optional context as Or.inr trivial (DECLINE); a caller that pays or relays one of them selects an earlier arm. The pin below lists, per opener and caller, how each optional context is supplied, and the summary counts the all-DECLINE callers — the sites item 375 calls "the seven opener arms with no sink". A caller that is not all-DECLINE is not a fallback site, whatever the parser says about its inputs.

                  The two splitting builders' h_res_land (item 380, PR #146 review follow-up) #

                  accum_block_on_pendingBlock / accum_block_on_pendingBlockContent hand the opener (through indicator_open_map) an h_res_land built by a CASE SPLIT, and WHICH arm a proof takes is a term-level fact (§7): Priority 48's walk reads the LANDING (no pop, own level), not the arm. This pin reads the arms off the proof terms, with the edge walker, per builder: every leaf of the split, NAMED BY ITS PATH through the nested splitters (Edge.leafPath, <splitter>#<arm> per hop) with its kind and source. The split is Or.casesOn on the park's h_closeF: arm 1 is the frameless park (DECLINE, closed); arm 0 opens dite on hmem — its arm 0 the resume Or.inl ⟨ks', …⟩ from the park's closeF + resumeAt (PAY, free) and its arm 1 the Classical.em (s_prep.indents = sc.indents) read as Or.elim (a two-arm split since this item, RelaySupplyCensus.isTwoArm), whose arm 0 is the NO-POP landing — Or.inr trivial, where the accepted root sibling a: 1⏎b: 2 lands (item 380's re-read) — and whose arm 1 holds item 378's popped landing: the uncovered park and lo > k (DECLINE), the two absurd refutations of the sequence top (VIA absurd), and the live register's : (DECLINE). Item 381 pays the no-pop arm from the park's own closeF on a non-nil compact tail: exactly the …>Or.elim#0 leaf flips DECLINE → PAY at both builders, and no other leaf moves. This pin is the baseline that payment is read against (§10: re-run before spending).
