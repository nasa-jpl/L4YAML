    The ghost-index census (DOCS item 331) #

    Row 12's two open forks (items 320 and 325) were both priced as a choice between widening a park's alternative with a proof-side disjunct and restating a field. Read together they are one question: which indices of the accumulation invariant are proof-side data standing in for scanner state? That is the question Blueprint Rule 8 answers for the future, and this file counts for the present.

    The classes #

    Every binder the invariant's carriers introduce — a parameter, an index, a constructor field, or a quantifier inside a field's statement — is one of:

    classwhat it isghost?
    surfacea SurfPos, or a predicate on positionsno — the correspondence is the theorem
    statethe ScannerState the carrier is aboutno
    propa Prop binder — a continuation, a route, a fact about the stateno — obligations are the induction hypothesis
    scalara Nat, Int, Bool, Char, context, token array …not counted as ghost here: most are grammar parameters (n, c) or pinned to the state by an inequality
    snapshotan Option ScannerState — a whole scanner state carried as an indexyes
    ghosta List FrameLevel (the frame lists — a mirror of sc.indents until Covered is an equality, item 332), a List Nat (the value-line chains), an Array Bool (the kinds and the key mask), a FrameTailyes unless pinned to a projection of the state
    disjunctnot a binder: an ∨ inside a field's statement, recorded at the fieldthe shape Rule 8 forbids when the alternative restates state (PackAlt, item 320's (A)); pinned per field so none can join unnoticed

    Rows are keyed by the FIELD they stand in (ctor[i].name), not only by the constructor: a binder moving from one field to another, or an ∨ added to a field, moves a row even when the counts do not (Devin Review on PR #7).

    The last two columns are the rule's subject. A snapshot or a ghost datum either (a) is proved equal to a projection f sc of the live state — the kinds index already is (sc.flowStack, 9b(i)) — or (b) names state the scanner does not have, in which case the scanner is incomplete and the field is added to ScannerState (item 299's docStartLine, item 48's explicitKeyCol, the definedAnchors argument in DOCS.md). What the rule forbids is the third option the two forks offered: a new proof-side disjunct or index carried beside the data the scanner already holds.

    What the census is and is not #

    It is a reading of TYPES, taken from the environment: the carriers' telescopes, their constructors' fields, and every ∃/∀ binder inside those fields' statements (that is where the List Nat chains live — ∃ ns : List Nat, ∀ nv ∈ ns, …). It does not read proofs, and it does not decide which ghost row is a projection and which is a missing field: that is each row's own item, priced by a probe (item 325's 1001/1002 pattern). The pin below is the list to shrink; a row leaves it when its carrier is re-indexed by a projection or a field, and nothing may join it (Rule 8).
