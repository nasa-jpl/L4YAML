    refLex output has the shape of a Skeleton — the decidable half (Rule 2) #

    refLex_sound : refLex input = some segs → Skeleton 0 input.toList segs is the next serialization lemma. Skeleton is a Prop over surface derivations, so it cannot be decided; this guard decides every side condition of SegAt/Skeleton that is boolean — the segments concatenate back to the input, each event lexeme is well-formed and maximal, document markers sit at column 0, directive lines start with % and end in a break, other runs are non-empty, event-free and never adjacent — on a fixed grid of inputs, so a mis-segmenting arm of step fails here before a proof is attempted.

    History: the first grid refuted the directive arm — %TAG ! !x⏎⏎--- a was segmented other "⏎" :: docStart …, the blank line between the directive and --- emitted BEFORE the directive text it follows (skeleton_text false). [79] s-l-comments lets a directive absorb the blank and comment lines after it; commentLines now does the same.
