    A blank fold line's tab is measured against the floor (DOCS item 62) #

    [70] l-empty(n,c) opens with s-line-prefix(n,c) or [64] s-indent-lt(n), and both begin in [63] s-indent, which is spaces (§6.1). A tab is admitted only by [69] s-flow-line-prefix(n)'s trailing s-separate-in-line? — that is, only once the n spaces are already there — and s-indent-lt(n) takes its break immediately after its short run. So a blank interior fold line whose white run reaches a tab BEFORE the floor matches neither arm, and both pipelines used to fold it anyway.

    This is a RUNTIME narrowing: the accepts below were already accepts, the refusals below were accepts and are now tabInIndentation — reported at the blank line's own tab, which is where the fold's existing §6.1 gate reads once the blank-line loop stops there.
