    Parity of the implemented_by scalar trims with their List Char specs #

    trimTrailingWSIx, stripTrailingNewlines and takeCharsIx are defined over List Char for the proofs and run through *Impl bodies that walk back from the end of the string. #guard evaluates with the compiler, so calling the spec-named function here exercises the Impl; the right-hand sides restate the List Char bodies literally. Every string of length ≤ 5 over an alphabet that mixes the trimmed characters (space, tab, line feed), a plain ASCII letter and a two-byte character is checked, so byte/char offsets are exercised too.
