        structure DescendTailDualUseSeparatorSuccessor.DeepGuard (Succ : Tok → Prop) (l : List Tok) (lo hi : Nat) :
        Prop

        The toy "deep content guard", parameterized by the allowed separator-successor class Succ (the map analog uses (· = .key), the seq analog a content-start predicate). The body head is a Succ token, and every depth-0 .fe separator is followed by a Succ token. This is the toy of FlowBodyContentDeepMap / FlowBodyContentDeepSeq, whose advance edges read exactly the separator-successor.

        • head : Succ (tokAt l lo)
        • sepSucc (k : Nat) : lo ≤ k → k + 1 < hi → tokAt l k = Tok.fe → Succ (tokAt l (k + 1))
