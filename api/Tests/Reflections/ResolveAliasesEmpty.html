    Reflection 603 -- resolveAliases on empty anchors is identity (R603) #

    resolveAliases_empty (§5.0a) asserts that for any YamlValue, resolving aliases against an empty anchor table #[] is the identity function:

    theorem resolveAliases_empty (v : YamlValue) : v.resolveAliases #[] = v

    This is a KEY SIMPLIFICATION LEMMA for the compositionality chain in the non-scalar branch of the Front-B sequence locality proof: it collapses items'' = items'.map (fun v => (v.resolveAliases #[]).stripAnchors) to items'' = items'.map YamlValue.stripAnchors since the emitter never produces anchors, so anchor tables in parsed output are #[].

    Inhabitation-debt check #

    • Rule 1 (antecedents reachable): the theorem has NO hypotheses — v : YamlValue is the only input. Every inhabitant of YamlValue is a reachable antecedent. The four concrete checks below witness all four constructors.

    • Rule 2 (conclusion non-vacuous): the native_decide checks show that for concrete scalars, aliases, sequences, and mappings, resolveAliases #[] does return the original value unchanged.

    • Rule 3 does not apply (no universal in the precondition).
