    Reflections — runnable proof-engineering demonstrations #

    This library collects the self-contained (core Lean, no L4YAML import) runnable illustrations of the proof-engineering principles documented as numbered Reflections in Blueprint/08-initiative-4-intrinsic-foundations.md. They are kept separate from the behavioural L4YAML test suites (parsing/emitting/round-trip) because they assert methodology, not library behaviour: each is a toy model whose #guard/#guard_msgs/#eval/by decide checks fail the build if the principle's positive/negative witnesses ever drift.

    Each module names the Blueprint Reflection it illustrates:

    • ComplementGuardNotSufficient — Reflection 333 (the COMPLEMENT of a sufficient dispatch guard need not be a sufficient guard — the toy of recseqbody_descend, the DESCEND arm. A spine-walk splits into ADVANCE (p past the head entry) and DESCEND (p inside it). The ADVANCE guard bal lo p = 0 ∧ lo < p is SUFFICIENT for "past the head"; the NAIVE negation bal lo p ≥ 1 is NOT sufficient for "inside the head" — p may be nested in a LATER entry (floor-blind, [[ref-floor-blind-gate-admits-cross-sibling]] on the complement side). The real DESCEND guard is the window-absolute FLOOR ∀ i ∈ (lo,p], bal lo i ≥ 1. Witness 1 , [ [ 2 ] ] (interior of [1,[[2]]]): a SCALAR head 1 (span [0,1)), then a doubly-nested seq. NEGATIVE (#guard): bal 0 3 ≥ 1 holds so the negated guard fires, yet p = 3 ≥ headEnd = 1 (past the head) and the FLOOR fails — bal 0 1 = 0 (the head's return-to-0); the floor is the discriminator the bare ≥ 1 lacks. NEGATIVE (#guard): delta op = delta mop — a seq opener and a map opener share delta +1, so head-is-.seq is provably NOT a balance fact and enters as the dispatch hypothesis h_lo_open, not a derivation. POSITIVE (proven floor_implies_in_head, the crux of recseqbody_descend's h_p_lt): abstractly over any B, if the head balances to 0 at its end m (B m = 0, lo < m) and the floor holds over (lo,p], then p < m — the floor at i = m would force B m ≥ 1, contra = 0. The guard/complement analogue of [[ref-converse-forward-invariant-asymmetry]]; applies [[ref-window-absolute-gate-subset-restriction]] / [[ref-minimal-pair-extracts-the-gate]])
    • AdvanceArmBalanceFree — Reflection 334 (the GENERAL ADVANCE arm is BALANCE-FREE once the caller supplies the decomposition — the toy of recseqbody_advance_general. R332's recseqbody_advance guarded advancing past the head with a BALANCE fact bal lo p = 0 and spent its bulk USING that balance to RECONSTRUCT the structural p ≥ lo + e.length. R334 finding: the balance was never intrinsic to advancing — the CALLER already extracts the head entry and dispatches on p ≥ lo + e.length, so it already holds that inequality AND the cons decomposition body = head ++ sep :: rest; pass them DOWN and the balance machinery EVAPORATES, leaving pure slice algebra + one opener-vs-separator inequality. Witness 1 , [ [ 2 ] ]: SCALAR head 1 (headEnd = 1), then a doubly-nested seq. NEGATIVE (#guard): bal 0 3 = 1 ≠ 0 so the balance route cannot advance at the nested p = 3, yet p ≥ headEnd (the structural route can); the separator/opener tokens differ (tok headEnd = .comma ≠ .op = tok 3) so p ≠ headEnd is a CONSTRUCTOR inequality, not a balance fact. POSITIVE (proven advance_rebase): GIVEN head ++ sep :: rest, the re-base (head ++ sep :: rest).drop (headLen + 1) = rest is pure List.drop_append — no balance, no floor. POSITIVE (proven sep_ne_opener): if body[headLen]? = some sep, body[p]? = some opener, sep ≠ opener, then p ≠ headLen. The upstream dual of [[ref-reconstruct-in-place-over-relocate]]; resolution pattern for [[ref-complement-guard-not-sufficient]]; an [[ref-additive-parallel-type-over-shared-edit]] sibling)
    • SeveredEdgeBoundsNavigator — Reflection 335 (a SEVERED recursion edge bounds a navigator's domain; a PATH-blind gate admits windows past it — the toy of the SeqMapPathNestedProbe de-risk that REFUTED rec_seq_body_nested_project's totality. A producer navigating a recursive deliverable can only reach windows whose PATH lies within the type's STORED edges; a member that PROJECTS rather than STORES the sub-deliverable (RecSeqEntry.map carries WellBracketed, not RecSeqBody) SEVERS the navigation. The consumer gate is PATH-BLIND (pins the IMMEDIATE enclosure, not the path), so it admits a map-PATH-nested seq window the navigator can't inhabit — invisible to a probe that only descends the navigable case; probe the PATH. Toy Body: .seq STORES the inner Body, .map PROJECTS to a weaker Flat. NEGATIVE (#guard): bodyInner? (.map (.wrap .leaf)) = none (navigator dies at the severed edge) though flatIsSeqHead (.wrap .leaf) = true (gate passes); map_never_navigable/seq_always_navigable show the severed edge is intrinsic to the constructor. POSITIVE (proven flatProvider): serve the gate-passing target from the WEAKER Flat substrate — the fix is RESTRICT the navigator + a flat provider, NOT strengthen the type. Sharpens [[ref-stored-vs-projected-severs-recursion-edge]] + [[ref-probe-provider-head-blind-gate]]; totality-refuting variant of [[ref-downstream-derisk-restores-upstream]])
    • AggregateCollapsesStructuredSeparates — Reflection 336 (the dispatch is the un-aggregated STRUCTURED STATE, not a numeric aggregate of it — the toy of SeqPathDispatchProbe. After a [[ref-severed-edge-bounds-navigator-domain]] de-risk refutes a navigator's totality, find the DISPATCH partitioning the path-blind gate's windows into navigable vs unreachable by probing a numeric AGGREGATE against the un-aggregated STRUCTURED STATE it was folded from, over a minimal pair. Toy: a typed-frame Stack; depth is the Nat aggregate (the flowBracketBalance analogue), pathAllSeq reads the whole stack (the btFold analogue), topFrame is the gate's path-blind projection. NEGATIVE (#guard + aggregate_collapses): the map-path stack [true,false,true] and all-seq [true,true,true] have EQUAL depth 3 and EQUAL topFrame some true — the aggregate COLLAPSES the pair (REJECTED; the collapse IS the necessity leg). POSITIVE (#guard + example): pathAllSeq is false vs true — the buried map frame SEPARATES them; the structured state read WHOLE is the dispatch, the gate's topFrame only its head-projection. Applies [[ref-minimal-pair-extracts-the-gate]] to a PATH-dispatch; discharges the reshaped next step of [[ref-severed-edge-bounds-navigator-domain]])
    • DomainRestrictionPreservationNegation — Reflection 337 (de-risk a navigator's DOMAIN-RESTRICTION with a PRESERVATION/NEGATION pair — the toy of SeqPathAllSeq's descend lemmas. When a severed edge bounds a navigator's domain ([[ref-severed-edge-bounds-navigator-domain]]) and you RESTRICT the domain to fence it out, prove BOTH that the KEPT edge maps the domain into itself AND that the EXCLUDED edge maps it OUT — it is the NEGATION that licenses dropping the excluded recursion arm, not the preservation alone. Toy: a typed-frame Stack, InDomain = nonempty all-true (the SeqPathAllSeq analogue), pushSeq/pushMap the two edges. POSITIVE (proven preservation): pushSeq keeps an all-true stack in domain (the seq head discharges the restriction — seqPathAllSeq_descend). NEGATIVE (proven negation): pushMap BREAKS it (a map head is out-of-domain ⇒ no fifth map-mirror arm — seqPathAllSeq_map_push_breaks). dominance: the domain implies TOP true (seqEnclosed_of_seqPathAllSeq). #guards pin the real minimal pair's stacks [true,false,true] (out) vs [true,true,true] (in). Lifts [[ref-converse-forward-invariant-asymmetry]] / [[ref-push-blind-frame-dependent]] from the TOP to the whole structured state [[ref-aggregate-collapses-structured-separates]])
    • ProducerStopsAtSeveredEdge — Reflection 338 (a PRODUCER stops at a severed edge as a leaf; a NAVIGATOR dies there — the toy behind rec_seq_body_nested_project's one-line landing. When a severed/projecting edge makes a NAVIGATOR non-total ([[ref-severed-edge-bounds-navigator-domain]]), check whether the deliverable can be PRODUCED instead of navigated before restricting the domain. Toy: a Carrier tree whose box member stores only a flat Bool (no recursive child — the RecSeqEntry.map analogue). NEGATIVE (proven severed_navigation_stuck): navigate DIES at a box window — it must descend INTO the member and there is no child (R335). POSITIVE (proven severed_production_total): produce STOPS AT the box, emits the leaf, recurses no further — TOTAL where navigation dies (seqWindowRecSeqBody's near-leaf map oracle). kept_edge_agrees: the two agree on the KEPT seq edge, diverging only at the severed one. #guards pin the divergence: a box-buried window navigates to none but produces .box true. For a Prop deliverable the two are interchangeable (proof-irrelevance) ⇒ prefer production, it sidesteps the edge; the domain restriction survives only as the consumer's routing tag ([[ref-coerce-to-weaker-reuse-wrapper]]), the four navigate-around arms an alternative not a necessity)
    • ProbeRefutesComplementProvider — Reflection 339 (a probe of a would-be COMPLEMENT provider REFUTES its necessity — the toy behind seqEnclosed_of_seqTypedInterior's one-line landing. When a navigator framing demands a domain PARTITION + a second provider for the excluded windows, PROBE before authoring: is the producer even sensitive to the partitioning predicate, is its real need PATH-INVARIANT, and does the consumer's GATE definitionally contain it. Toy: a Stack of typed frames; Enclosed = the HEAD is a seq (path-invariant); StrongPath = the WHOLE stack all-seq; Gate whose enc field IS Enclosed. BRIDGE (proven enclosed_of_gate := g.enc): the gate supplies the producer's need in one line ([[ref-conjunct-of-projection-is-free-field]] at the gate). PROBE (proven probe_not_strongPath + probeGate): the window [true, false] FAILS StrongPath (a false deeper down) yet the Gate HOLDS — so the producer serves the ¬StrongPath window through the gate, NO complement needed. #guards pin it: probeStack.all (·==true) = false but probeStack.head? = some true. So StrongPath is VESTIGIAL and ONE producer serves the whole gated domain — the size-down dual of [[ref-downstream-derisk-restores-upstream]] (the discriminator was never needed; the gate carried it))
    • EndFreeGateUnderdeterminesClose — Reflection 340 (an END-FREE gate underdetermines a window's CLOSE — the toy behind the (i'-b-B2c-provider-from-gate) probe SeqGateWindownessProbe. A provider quantified under a gate whose conjuncts constrain only window-INTERNAL invariants (balance, enclosure mark, Dyck floor — none mentioning the token AT the end b) cannot read its structural close off get s b. Toy: Tok := op | cl | it | sep; bal/windowBal over a slice; an END-free Gate with one balance-0 conjunct. PROBE (proven gate_24 + end_24_not_close): the b ≠ close window [2,4) = it sep (mirror of "1" ,) on W = op op it sep it cl sep it cl (mirror of [[1,2],9]) PASSES the gate yet get W 4 = it, NOT cl. BRIDGE (proven located_close_24): the close is read off the LOCATED enclosing structure hiS = 5 (get W 5 = cl), the window SELECTED inside by 4 ≤ 5 — never off b, mirroring seqDescent_provider_of_located. #guards pin it: windowBal W 2 4 = 0 but get W 4 ≠ cl, while get W 5 = cl. END-dual of [[ref-probe-provider-head-blind-gate]] (head-blind admits spurious-HEADED windows; end-free admits spurious-ENDED ones); the existing satisfiability probe MASKED it by only using b = close windows. SHARPENED by Reflection 356 (gate_admits_three_ends/close_token_separates_three_ends on V = op it sep it sep it cl): a SETTLED next-step pointer (the emission-spine wrapper nestedSeq_recseqentry_locate, R355) re-credited balance-0 with pinning b; re-running the probe shows the gate admits not one but ARBITRARILY MANY non-close ends (a seq of n elements has n-1 separator ends, all balance-0 + floored), so b is pinned by the consumer's explicit close hypothesis tokens[hi]!.val = .flowSequenceEnd — seqWindowRecSeqBody's fourth G-conjunct — not by the interior gate; re-probe a boundary-pinning attribution even when a settled pointer states it)
    • ContextFreeAdapterKnot — Reflection 343 (a CONTEXT-FREE IH adapter cannot thread a CONTEXT-DEPENDENT carrier fact — the toy behind the (i'-b-B2c-desc-fixpoint-assembly) probe.
